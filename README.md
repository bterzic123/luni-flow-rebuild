# Growth Audit — Scanner by Luni

**Live:** https://bterzic123.github.io/luni-flow-rebuild/
**Prototype on a phone:** https://bterzic123.github.io/luni-flow-rebuild/?open=proto

Five ranked ideas for Scanner – Scan PDF, ID & Docs (iOS), each rebuilt as a working screen in a clickable prototype of the onboarding and paywall. The screens use Scanner's own design. Only the order changed.

| # | Idea | Screen | Potential outcome |
| :-- | :-- | :-- | :-- |
| 01 | Offer the year when they close the paywall | Offer on close | ARPU +10–15% |
| 02 | Ask what they scan, then say it on the paywall | What you scan → Paywall | CR +15–20% |
| 03 | Pitch the free trial once, not three times | Reminder | CR +10–15% |
| 04 | Show their scanner set up before the price | What you do → Set up | CR +10–15% |
| 05 | Put your 4.8 and 30M+ users next to the plans | Paywall | CR +10–15% |

**Grounding.** Every price, rating, user count and feature line comes from Scanner's own App Store listing and in-app screens. The 42% saving is arithmetic on those prices: $89.99 a year against 12 × $12.99.

Impact ranges are Adapty's expected effect from teardowns and A/B tests across subscription apps. They are not measured lift for Luni.
